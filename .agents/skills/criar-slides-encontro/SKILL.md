# Slides históricos

SMA não cria slides para encontros novos. O material de cada encontro é o roteiro público autoguiado e a prática correspondente.

O acervo em `slides/` permanece como registro histórico. Só corrija um deck existente quando o usuário solicitar explicitamente a correção de um erro factual já publicado. Nessa exceção:

1. leia o roteiro e a prática correspondentes para confirmar o erro;
2. altere apenas o necessário na fonte Marp existente;
3. renderize o HTML e o PDF correspondentes, sem edição manual dos derivados;
4. inspecione a alteração e execute as validações pertinentes.

Não crie, derive, redesenhe ou atualize decks para novos encontros. Se o pedido buscar apoio à condução presencial, melhore o roteiro e a prática para que também sejam úteis sem o professor presente.
